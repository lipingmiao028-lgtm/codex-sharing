使用 skill-creator 创建一个名为 website-feature-capture 的全局 SKILL，位置为当前用户主目录下的 .agents/skills/website-feature-capture/。用途：采集外部网站的功能、页面和交互，形成中文功能说明与长截图，供产品设计参考。

技能要求：
1. 目标网址、采集范围、已有目标标签及成果保存位置均由调用者传入；技能不内置案例网址、项目名、知识库路径或设计文档位置。先复用用户已打开的目标标签页，确认页面身份和可见权限；不新建浏览器或标签、不复制登录状态、不重启或关闭用户浏览器，不读取凭据。
2. 先清点可见菜单、链接、按钮、页签和路由变化，建立范围内的遍历清单；再沿页面中的安全入口遍历列表、筛选、详情、页签、抽屉和不提交的编辑页，不只截一级菜单。
3. 使用同一自动化连接完成清点、遍历、截图和核对。使用技能专属或通用浏览器自动化环境，不借用无关项目的依赖。复用当前 Chrome 时优先使用 Chrome DevTools MCP 的 auto-connect，选择网址匹配的已有顶层标签；不使用临时浏览器替代，不反复请求连接权限。无法连接时说明阻塞。
4. 只读采集：允许查看、导航、翻页和不修改数据的筛选；保存、提交、发布、删除、审批、发送及状态变更等入口只记录，不执行。忽略无关标签页，记录中隐藏个人信息和敏感数据。
5. 每个有新增功能信息的页面或状态保存一张可读的长截图。等待加载完成，处理页面内部滚动、懒加载和虚拟列表；不因翻页或参数变化重复保存相同结构。截图按数字序号和中文功能名命名。
6. 默认生成 功能模块说明.md 和同级 assets/ 截图目录，保存位置由调用者指定。文档包含来源与采集时间、产品定位、分层功能清单、筛选与字段、状态与操作、详情与编辑入口、跨模块关系、观察到的流程、截图索引和覆盖限制。使用相对图片链接，区分实际观察与推断，不混入其他网站功能。
7. 完成后核对范围覆盖、截图数量和可读性、文档链接，以及没有线上写操作。退出时只断开控制连接，不关闭浏览器、上下文或标签页。记录未访问、无权限、加载失败和未执行的危险操作，不伪造采集结果。

生成 SKILL.md 及必要的配套说明或辅助脚本，路径与命令兼容团队使用环境。校验名称、描述、触发条件、文件引用和调用方式。已有同名技能时检查差异，只更新需要调整的内容。
